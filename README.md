# MLA Tech: Interactive Networking Lab & Academy

[![Live Demo](https://img.shields.io/badge/demo-live-blue.svg)](https://mohammadlotfia.github.io/networkinglab/)

**MLA Tech** is a high-fidelity, interactive networking simulator designed to help students and professionals master the complexities of digital infrastructure. Specifically built for **CompTIA Network+ (N10-009)**, **Security+ (SY0-701)**, and **Cisco CCNA (200-301)** candidates.

## 🚀 Explore the Lab
Developed by **Mohammad Lotfi Akbarabadi**, this platform bridges the gap between theoretical certification objectives and practical terminal-ready skills.

### [👉 Launch the Interactive Lab](https://mohammadlotfia.github.io/networkinglab/)

---

## 🛠 Features

### 1. Interactive OSI Model Simulator
Visualize data flow across all 7 layers of the OSI model. 
- **Layer 1-4:** Detailed animations of Physical, Data Link (VLANs), Network (Routing), and Transport (TCP/UDP) layers.
- **Layer 5-7:** Conceptual breakdowns of Session, Presentation, and Application layers.

### 2. Comprehensive Subnet Calculator
Master the binary math required for modern networking.
- **IPv4 Subnetting:** Calculate Network IDs, Broadcast addresses, and usable host ranges.
- **IPv6 Support:** Understand hexadecimal addressing and 128-bit address space segmentation.

### 3. Networking Academy (Certification Guides)
Curated articles and lab walkthroughs for:
- **CompTIA Network+ N10-009:** Learn about SASE, SDN, and wireless standards (Wi-Fi 7).
- **Cisco CCNA 200-301:** Practice OSPF configuration, NAT, and Access Control Lists.
- **Security Essentials:** Deep dive into the CIA Triad, Threat Actor taxonomy, and Nmap auditing.
